Spec Language Syntax

Declarations & Types

Spec declarations use the <Type> is <Name>: <Value>; pattern consistently across locals, fields, parameters, classes, and functions.

Int is count: 0;
String is greeting: 'Hello';
Array of String is items: Array(['one', 'two']);
Map of String to Int is scores: Map:init();

Classes, Inheritance, and Imports

Classes declare their package with replace [String] is namespace: [...] and import dependencies with using. Instance-importing a utility class with as ClassName() exposes its methods directly on self.

Class of BaseWidget is CounterPanel{
	replace [String] is namespace: ['app', 'ui'];

	merge [[String]] is using: [
		['base', 'sys', as Conditional()],
		['base', 'sys', as Loops()]
	];

	Int is value: 0;

	Function of Int is increment(Int is by: 1){
		value: value + by;
		return value;
	}
}

		sum: sum + n;

The Spec Programming Language

Spec is a statically typed, self-hosting systems and application language that compiles directly to native machine code via LLVM IR and Clang.

Spec combines clean object-oriented and algebraic modeling with deterministic Automatic Reference Counting (ARC) — no tracing garbage collector pauses — and structured concurrency.

Core Highlights

  • Named Parameters Everywhere: Every function call and constructor uses explicit name: value arguments, making call sites self-documenting.
  • Deterministic ARC + Claim Pool: Heap objects are reference-counted deterministically with compile-time scope release and pool elision.
  • Algebraic Enums & Pattern Matching: Tagged unions (such as Result of T to E and SemType) dispatch cleanly through match(on: ..., when: [...]).
  • Control Flow as Library Constructs: if, while, times, range, and match are library functions inlined directly into zero-overhead native loops and branches by the compiler.
  • Structured Concurrency: ThreadScope:open, typed Channel, Task, and Parallel guarantee worker lifetimes never outlive their lexical scope.

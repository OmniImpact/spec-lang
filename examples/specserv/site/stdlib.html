Spec Standard Library

base:core

Core root types: Any, String, Str, Result, SpecError, Stringable, and Mergeable.

base:struct

Generic collections: Array, List, Map, Stack, and Sort.

base:data

Structured data parsers and serializers: Json (with JsonNumber, JsonBool, JsonNull) and Xml / XmlNode (strict XML and HTML5 DOM parsing).

base:net

Networking and web primitives: Socket (TCP client/server), Http (HTTP/1.1 client), TlsClient, Url, and SpecServePage.

base:sys & base:sys:thread

System interfaces: File, Dir, Process, Time, DateTime, Simd, Conditional, Loops, ThreadScope, Task, Channel, and Parallel.

base:theo & base:cleo

Terminal UI and CLI frameworks: TheoApp, Frame, Grid, Panel, ListView, TextInput, Button, PixelCanvas, and Cleo.
